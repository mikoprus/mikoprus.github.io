Mikołaj Prus

Senior software developer working in React, TypeScript, React Native and Electron.

Since 2022 I have been building remotely proctored, high-stakes English tests for Pearson: camera, microphone and audio code that has to work on the test taker’s own laptop or phone, checks that keep the exam fair, and the performance and accessibility work around them. I am now co-building, full-stack with React and Spring Boot, a speaking test in which candidates hold a real-time voice conversation with an AI character. Before that I shipped apps in fintech, messaging and SaaS. I also build my own products, most recently skierowanie.net, a telemedicine service for MRI referrals.
